プライバシーポリシー

本ページでは、ブラウザ拡張機能「YouTubeタイムスタンプツール🍥」（以下、本拡張機能）における利用者情報の取り扱いについて説明します。

1. 個人情報の収集について

本拡張機能は、氏名、メールアドレス、電話番号などの個人を特定できる情報を一切収集しません。また、ユーザーの閲覧履歴をサーバーに送信することもありません。

2. データの保存場所

本拡張機能で記録されたタイムスタンプおよびメモの内容は、すべて利用者のブラウザ内のローカルストレージ（chrome.storage）に保存されます。これらのデータが外部のサーバーや第三者に提供されることはありません。

3. 外部サービス（翻訳API）の利用

タイムスタンプの記録時に「英語翻訳」を行うため、入力されたテキストのみを外部API（MyMemory API）へ送信します。この通信は翻訳結果を取得するためだけに使用され、個人情報が送信されることはありません。

4. 権限の利用目的

本拡張機能は、YouTubeドメイン（www.youtube.com）において、動画の再生時間の取得および操作用UIを表示するために必要な権限のみを使用します。
